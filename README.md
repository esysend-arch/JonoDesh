# JonoDesh

সত্য • দ্রুত • দায়িত্বশীল — সারা বাংলাদেশের (৮ বিভাগ, ৬৪ জেলা) বাংলা অনলাইন সংবাদ পোর্টাল ও নাগরিক প্ল্যাটফর্ম ("জনগণের কথা")।

এই রিপোজিটরিতে তিনটি অংশ আছে:

| অংশ | কোথায় | কী |
|---|---|---|
| সিঙ্গেল-পেজ সাইট + সার্ভার | `index.html`, `server.js`, `data/db.json` | নির্ভরতাহীন Node সার্ভার; অ্যাডমিন প্যানেল সহ |
| Next.js পোর্টাল (Supabase) | `web/` | বিস্তারিত: `web/README.md` |
| Android অ্যাপ | `app/` | Compose অ্যাপ; `app/src/main/assets/web/index.html` অফলাইনে চলে |

## সার্ভার চালানো

```bash
node server.js
# http://localhost:3000   (অ্যাডমিন: nhmunna2004)
```

- ডিফল্ট অ্যাডমিন ইউজার `nhmunna2004`; পাসওয়ার্ড কোডে হ্যাশ আকারে আছে। বদলাতে চাইলে `ADMIN_USER` ও `ADMIN_PASSWORD` এনভায়রনমেন্ট ভ্যারিয়েবল দিন।
- অ্যাডমিন প্যানেলে লগইন করে "ইউজার" ট্যাব থেকে সম্পাদক/মডারেটর/রিপোর্টার যোগ করা যায় (পাসওয়ার্ড কমপক্ষে ৮ অক্ষর)।
- `data/db.json`-এ নমুনা সংবাদ আছে; অ্যাডমিন প্যানেল থেকে মুছে নিজের সংবাদ দিন।
- `index.html` বদলালে `app/src/main/assets/web/index.html`-এও কপি করুন:
  `cp index.html app/src/main/assets/web/index.html`

## Android

`app/` Android Studio-তে খুলুন। অ্যাপের ভেতরের ওয়েব ভিউ অফলাইনে নমুনা সংবাদ দেখায়; অ্যাডমিন লগইনের জন্য সার্ভার প্রয়োজন।
নেটিভ অ্যাডমিন স্ক্রিনের পাসওয়ার্ড হ্যাশ `AdminScreen.kt`-এর শেষে `ADMIN_PASSWORD_SHA256`-এ আছে; নিজের পাসওয়ার্ডের হ্যাশ বসান।
